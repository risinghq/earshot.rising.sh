# Manual

1. [music-stats](music-stats.md): install the command and write your top tracks
   to a Gist.
2. [GitHub Actions](github-actions.md): update the Gist or upload your plays, on
   a schedule, from a repository you own.
3. [Configuration](configuration.md): environment variables, `.env`, logging and
   errors.
4. [Providers](providers.md): get Last.fm and YouTube Music credentials, and how
   each source is read.
5. [Output](output.md): what the Gist and the upload contain.
6. [Architecture](architecture.md): the code map.
7. [Releasing](releasing.md): publish a version.
8. [Web app](web-app.md): the design of the hosted service.
9. [Web deployment](web-deploy.md): create and deploy the hosted profile.

To change the code, start with [Contributing](../.github/contributing.md).
